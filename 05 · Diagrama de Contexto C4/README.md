# Diagrama de contexto — SkyCampus MVP

Artefactos del reto 5, nivel Chimchar:

- `Diagrama_Contexto_SkyCampus.drawio`: fuente editable para draw.io.
- `Diagrama_Contexto_SkyCampus.svg`: exportación vectorial del diagrama.

El diagrama presenta los tres actores del HTML (Operador de drones, Solicitante y Admin), los datos que envían al sistema y las respuestas que reciben. El MVP no integra sistemas externos; el control de los drones es local.

La notación visual sigue la referencia de clase: las personas aparecen en verde y el sistema en construcción en azul. No se muestra un sistema externo en rojo porque el alcance Chimchar especifica que no hay integraciones externas. Las relaciones se dibujan con flechas discontinuas, etiquetas de datos y sentido de flujo.
